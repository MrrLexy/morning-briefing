# Morning Market Update

Fixed income desk briefing. Renders to a single self-contained `index.html`,
published to GitHub Pages.

**Live:** <https://mrrlexy.github.io/morning-briefing/>

> **Read [DATA_POLICY.md](DATA_POLICY.md) first.** Bloomberg's terms prohibit
> redistributing Terminal data. `data.json` is gitignored and stays on the local
> machine; only the rendered `index.html` is ever published. This is a licensing
> constraint, not a style preference.

---

## Getting data in

Three paths. All write the **same** `data.json` schema, so nothing downstream
cares which one was used. Each stamps a different `source` value so you can tell
after the fact.

### A. Local Bloomberg Terminal

```bash
python fetch_bloomberg.py     # or double-click run_feed.bat
```

Needs `pip install blpapi` and the Terminal running on the same machine
(localhost:8194). `run_feed.bat` skips weekends.

→ `"source": "Bloomberg Terminal"`

### B. BBG Anywhere / web terminal — paste a grid

No Terminal API, no Excel add-in required.

1. Build a monitor with your securities as rows, using **real Bloomberg syntax**:
   ```
   GT2 Govt   GT5 Govt   GT10 Govt   GT30 Govt
   USGGT10Y Index   USGGBE10 Index
   LBUSTRUU Index   LUACTRUU Index   JBCDCOMP Index   BAMLH0A1HYBB Index
   BAMLC0A0CM Index   BAMLH0A0HYM2 Index   BAMLH0A3HYC Index
   MOVE Index   SPX Index   DXY Curncy   CL1 Comdty   USOSFR Index
   ```
2. Add field columns (include only what's available — gaps are fine):
   `PX_LAST`, `CHG_NET_1D`, `YLD_YTM_BID`, `OAS_SPREAD_ASK`, `DUR_ADJ_MID`,
   `RETURN_YTD`, `RETURN_QTD`
3. Select the grid **including the header row**, Ctrl+C, paste into Notepad,
   save as e.g. `paste.txt`.
4. ```bash
   python import_bbg_paste.py paste.txt
   ```

It translates Bloomberg syntax to the internal shorthand automatically
(`GT10 Govt` → `GT10:GOV`, `AGG US Equity` → `AGG:US`), and copes with how
Bloomberg grids actually format numbers: `1,234.56`, `(12.3)` for negatives,
`--` / `N.A.` for blanks. Tickers it can't map are **reported, not silently
dropped**.

→ `"source": "Bloomberg (manual paste)"`

### C. A CSV you've already normalized

```bash
python import_manual_export.py export.csv
```

Same idea, but no ticker translation — the first column must already be internal
shorthand (`GT10:GOV`). Use this if you're generating the CSV from Excel/BDP and
can control the ticker strings yourself.

→ `"source": "Bloomberg (manual export)"`

### Ticker shorthand reference

What goes in `data.json` (and in path C's CSV):

```
LBUSTRUU:IND  LUACTRUU:IND  JBCDCOMP:IND  BAMLH0A1HYBB:IND
BAMLC0A0CM:IND  BAMLH0A0HYM2:IND  BAMLH0A3HYC:IND  MOVE:IND
GT2:GOV  GT5:GOV  GT10:GOV  GT30:GOV
USGGT10Y:GOV  USGGBE10:IND
SPX:IND  DXY:CUR  CL1:COM  USOSFR:IND
```

Mapping rule: `Govt`→`:GOV`, `Index`→`:IND`, `Curncy`→`:CUR`, `Comdty`→`:COM`,
`US Equity`→`:US`. One exception: `USGGT10Y Index` → `USGGT10Y:GOV`.

Extra tickers for the watchlist panel live in `watchlist.json` and are picked up
at runtime — no code change needed to add one.

## Viewing locally

```bash
node server.js      # serves this folder on :8080, prints a LAN URL
```

The LAN URL works from a phone on the same network.

## Publishing

`index.html` is committed and served by GitHub Pages:

```bash
git add index.html && git commit -m "Market Update YYYY-MM-DD" && git push
```

Live in ~1–2 minutes. **Never** `git add data.json` — it's gitignored, keep it
that way.

## Gotchas

- **`index.html` is regenerated by an external process.** Hand-edits to it can
  be overwritten. The back-link to The Brain hub is marked with an HTML comment
  asking to preserve it; if it vanishes after a briefing run, that's why.
- **`fetch_bloomberg.py` imports `blpapi` lazily** (inside `bbg_fetch`) so the
  import scripts can reuse its schema helpers on machines without the Terminal
  SDK installed. Don't move that import back to the top of the file.
- **Stale data is silent.** Check `fetched_at` in `data.json` before trusting
  any number on the page.
- `*.csv` and `manual_export*` are gitignored so downloaded exports can't be
  committed by accident.
