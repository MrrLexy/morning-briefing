Bloomberg Data Converter
Excel template → data.json, without leaving the browser
Your data never leaves this device. This page has no server and makes no network requests. The file you pick is read and converted locally by JavaScript in this tab. Required by DATA_POLICY.md — raw Bloomberg values must stay on the licensed workstation.
Step 1 — Get the template

Download once and keep it. It is a grid of =BDP() formulas that refresh live every time you open it with the Bloomberg Excel add-in loaded.

Download bbg_template.xlsx
Step 2 — Refresh it in Excel
  1. Open bbg_template.xlsx on a machine with the Bloomberg Excel add-in.
  2. Wait for the formulas on the Data sheet to resolve to numbers. #N/A is fine — that field doesn't apply to that security.
  3. File → Save As → CSV (Comma delimited), under a new name. Saving as CSV converts formulas to plain values automatically — that is the “save as values” step, you don't need to do it separately.

Keep the .xlsx intact as your reusable template; save each day's CSV separately.
