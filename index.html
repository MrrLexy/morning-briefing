Data Sources & Methodology
  • Yields: US Treasury official daily yield curve CSV — all tenors 2Y–30Y. 2s10s & 5s30s computed from live data. Bloomberg upload overrides any field.
  • Spreads: ICE BofA IG/HY/EM OAS via FRED (BAMLC0A0CM, BAMLH0A0HYM2, BAMLEMCBPIOAS). Bloomberg upload overrides.
  • SOFR: sofrrate.com (primary, daily) — FRED SOFR series as fallback.
  • Futures / Risk: S&P, Dow, Nasdaq futures + DXY + VIX via yfinance (ES=F, YM=F, NQ=F, DX-Y.NYB, ^VIX).
  • Headlines: Reuters RSS (macro, M&A), BEA, Federal Reserve, BBC World — fetched at run time.
  • Bloomberg overlay: Download data/bloomberg_template.csv, fill value & as_of_date, save as bloomberg_data.csv in the data/ folder, re-run pipeline.
